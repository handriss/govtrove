Frequently Asked Questions

What is a PSC code?

A PSC (Product and Service Code) is a code the federal government uses to categorize what it’s buying in a specific contract. While NAICS codes classify the supplier’s industry, PSC codes classify the product or service being purchased.

What’s the difference between NAICS and PSC codes?

NAICS codes describe what your business does (your industry), while PSC codes describe what the government is buying (the product or service). A single contract has both: a NAICS code for the type of vendor and a PSC code for the type of purchase. For example, an IT staffing contract might use NAICS 541512 (Computer Systems Design) and PSC DA01 (IT Systems Development Services).

How are PSC codes structured?

PSC codes are 2–4 characters. Service codes start with a letter (A–Z) — for example, D = IT and Telecom, R = Professional Support, J = Maintenance and Repair. Product codes start with a number (10–99) — for example, 70 = IT Equipment, 65 = Medical Equipment. Longer codes are more specific.

How do I find the right PSC code for a federal contract?

Use the PSC Code Finder tool above — describe your products or services in plain English and it will match you to the most relevant PSC codes using AI. You can also look at the PSC codes on similar contracts you’ve seen on SAM.gov to identify which codes are commonly used for your type of work.
