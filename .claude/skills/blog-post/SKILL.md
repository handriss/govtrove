# Blog Post

Write and publish a new blog post for the GovTrove landing site.

## How to Write a Post

1. **Read an existing post** as a template — use `landing/blog/sam-gov-search-tips.html` or any recent post. Copy its full HTML structure including head, nav, footer, and mobile menu JS.
2. **Create the new file** at `landing/blog/<slug>.html` — use kebab-case slugs.

## Template Structure

Every blog post is a self-contained HTML file with inline CSS (no shared stylesheet beyond `theme.css`). The structure is:

```
<head>
  - <title> — format: "Post Title | GovTrove Blog"
  - <meta name="description"> — SEO meta description
  - <link rel="canonical"> — full URL
  - OG and Twitter Card meta tags
  - Anti-FOUC script + theme.css link
  - Google Fonts (Inter 400/500/600/700)
  - Inline <style> block (copy from template — all posts use identical CSS)
  - JSON-LD BlogPosting schema
  - Analytics script
</head>
<body>
  - Nav (fixed, with logo + links + ghost CTA button)
  - Mobile menu
  - <article> with .article-header and .article-body
  - Footer
  - Mobile menu toggle JS
</body>
```

## Nav Links

Must match the current landing page navigation:
- `/#problem` → "Why GovTrove"
- `/#faq` → "FAQ"
- `/blog/` → "Blog" (with `class="active"`)

The nav CTA should be a ghost button (not `btn-primary`):
```html
<a href="https://app.govtrove.com" class="btn nav-cta">Start Searching</a>
```

The `.nav-cta` CSS uses transparent background with accent border (defined in the inline style block).

## Article Meta

```html
<div class="article-meta">
    <span class="article-category category-{type}">{Label}</span>
    <span class="article-meta-separator">&middot;</span>
    <span class="article-date">{Month Day, Year}</span>
    <span class="article-meta-separator">&middot;</span>
    <span class="article-reading-time">{N} min read</span>
</div>
```

## Available Categories

Defined in `landing/theme.css` with dark and light mode variants:

| CSS class | Label | Color |
|-----------|-------|-------|
| `category-sam-gov` | SAM.gov Tips | Blue |
| `category-guide` | Guide | Amber |
| `category-set-asides` | Set-Asides | Purple |
| `category-naics` | NAICS | Green |

To add a new category, add `--category-{name}-bg`, `--category-{name}-text`, and `--category-{name}-border` variables to both the dark and light theme sections in `landing/theme.css`, then add a `.category-{name}` rule in the blog index CSS and the new post's inline CSS.

## Article Body Elements

The inline CSS supports these elements inside `.article-body`:
- `<p>` — body text (1.125rem, secondary color)
- `<h2>` — major sections (1.5rem, 2.5rem top margin)
- `<h3>` — subsections (1.25rem, 2rem top margin)
- `<ul>`, `<ol>` — lists with proper spacing
- `<blockquote>` — accent-colored left border with subtle background
- `<code>` — inline monospace with elevated background
- `<a>` — accent color with underline
- `.article-disclaimer` — italic muted text with top border (for attribution/legal)

## Article Footer

Every post ends with:
```html
<a href="/blog/" class="article-back">&larr; Back to Blog</a>

<div class="article-cta">
    <h3>{CTA headline}</h3>
    <p>{CTA supporting text}</p>
    <a href="https://app.govtrove.com" class="btn btn-primary">Start Searching</a>
</div>
```

## HTML Entities

Use HTML entities for special characters — the posts are plain HTML, not markdown:
- `&mdash;` for em dashes
- `&ndash;` for en dashes (number ranges like "80,000&ndash;100,000")
- `&middot;` for middle dots
- `&rarr;` / `&larr;` for arrows
- `&amp;` for ampersands in text and attributes

## SEO Checklist

- Title tag should include primary keyword + "| GovTrove Blog"
- Meta description under 160 characters, includes target keywords
- H1 matches the OG title (can differ slightly from `<title>`)
- Use H2/H3 hierarchy for scanability and featured snippet potential
- Format key data as bullet lists (better for featured snippets than inline text)
- Include internal link to `https://app.govtrove.com` in body text
- Add JSON-LD `BlogPosting` schema with headline, description, datePublished, author, publisher, url, mainEntityOfPage

## Post-Publish Checklist

After creating the blog post HTML file in `landing/blog/`:

1. **Update sitemap** — Add the new post URL to `landing/blog-sitemap.xml` with today's date as `<lastmod>`. **Not `landing/sitemap.xml`** — that file is generated by the `seo-pages` Lambda and `make deploy-landing` syncs with `--exclude "sitemap.xml"`, so edits to it never reach production.
2. **Update blog index** — Add the post as the first card in `landing/blog/index.html`:
   - Add to the JSON-LD `blogPost` array (first position)
   - Add an `<article class="blog-card">` as the first item in `.blog-grid`
   - Include: category badge, date, linked H2, excerpt paragraph, "Read more" link
3. **Deploy** — Run `make deploy-landing`
